# FL-012 · El agente registra lo que el clasificador dejó como consulta

| Campo | Valor |
|---|---|
| Área | B · Consulta, reclamo y registro |
| Actores | cliente, agente |
| Canal | WhatsApp |
| Disparador | "tengo una duda con un débito de ayer" (clasificador `UNCLEAR`); en el turno el cliente aclara que no lo reconoce |
| Reglas | `LAM-COMPLAINT-REQUIRED` |
| Depende del modelo | Sí (ver Oráculo) |
| Fuente | `docs/flows-catalog.md` FL-012; `docs/test-plan.md` §2.2, §4.3 y §4.5 |

## Entrada

- Mundo `qa-<runId>-sc11`, reloj `PAUSED`.
- Persona clon `C02'` (cargo `FEE-CARD-REPL` de $ 2.500 sin pedido en el manifest).
- Mensaje 1: "tengo una duda con un débito de ayer" (el clasificador lo deja `UNCLEAR`).
- Mensaje 2 del escenario, en el turno siguiente: "no lo reconozco, yo no lo pedí".

## Pasos

1. `wa.inbound` con el mensaje 1: sin registro; turno.
2. `wa.inbound` con el mensaje 2.
3. El agente llama `register_complaint(RECLAMO, UNRECOGNIZED_CHARGE)` antes de investigar.
4. El código manda el `COMPLAINT_ACK` fijo por la compuerta.
5. `conv.settleProbe` hasta `settled`; `snapshot`.

## Resultado esperado

- **R1** · Un reclamo `UNRECOGNIZED_CHARGE` con número correlativo y su entrada `FILED`. _Dónde:_ `snapshot.complaints[]`, `snapshot.register`.
- **R2** · `register_complaint` aparece en `TURN#` antes de cualquier tool de investigación o acción. _Dónde:_ `snapshot.turns[].results`.
- **R3** · El `COMPLAINT_ACK` sale con el texto fijo del código y `sender SYSTEM`, `ALLOWED` en la cinta. _Dónde:_ `snapshot.tape`.
- **R4** · `ackLatencyMs` medido desde el mensaje que expresó el reclamo (el mensaje 2). _Dónde:_ `snapshot.metrics`.
- **R5** · Una tool de investigación llamada antes del registro devuelve `COMPLAINT_REQUIRED` (lo asierta `U`). _Dónde:_ salida de vitest.

Negativos (se asiertan después de la quiescencia, `CONVENCIONES.md`):

- **N1** · Ninguna evidencia ni acción sin reclamo registrado.

## Oráculo

Fila `SC-11/6`, `SC-11/7` de §4.3. Hechos exigidos: `register_complaint` (con el tipo del reclamo) antes de toda tool de investigación. Alternativas aceptadas: ninguna.
