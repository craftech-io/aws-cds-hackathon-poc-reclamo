# FL-110 · Guards de CI: sin recepción SES, punto único de salida, términos prohibidos

| Campo | Valor |
|---|---|
| Área | N · Canal vivo y robustez |
| Actores | CI |
| Canal | — |
| Disparador | un PR que declara un receipt rule, un filtro de recepción, un MX o un MAIL FROM; una acción `sesv2:` en el template; un comando de envío fuera de `outbound/transports/`; un término de la lista externa |
| Reglas | — |
| Depende del modelo | No |
| Fuente | `docs/flows-catalog.md` FL-110; `docs/test-plan.md` §2.2 |

## Entrada

- Fixtures de los tests: un `aws.ses.ReceiptRule`, un `type: "MX"`, un `ses:SetActiveReceiptRuleSet` permitido, una acción `sesv2:` en el template, un comando de envío fuera de `outbound/transports/`, un `SendMessageCommand` fuera de `worker/enqueue.ts` y un término de una lista de prueba.
- En CI: la lista real `FORBIDDEN_TERMS` (secreto, fuera del repo).

## Pasos

1. `npm run lint:no-ses-receiving`, `npm run lint:chokepoint` y `npm run lint:forbidden` sobre cada fixture.
2. `ci-role.test.ts` sobre el template del bootstrap.

## Resultado esperado

- **R1** · Cada guard falla con archivo y línea ante su fixture. _Dónde:_ salida de vitest.
- **R2** · `lint:forbidden` falla cerrado con `CI=true` y la lista vacía, y nunca imprime el término (solo su posición en la lista). _Dónde:_ salida de vitest.
- **R3** · El rol de deploy deniega las acciones de recepción aunque el código las declarara (sin acciones `sesv2:`). _Dónde:_ `ci-role.test.ts`.

Negativos (se asiertan después de la quiescencia, `CONVENCIONES.md`):

- **N1** · Ningún término de la lista en la salida de ningún guard.

## Oráculo

No depende del modelo: son checks de CI sobre el código y el template del bootstrap.

## Pruebas que lo cubren

- **U (unitario)** · `scripts/lint/no-ses-receiving.test.ts`, `scripts/lint/chokepoint.test.ts`, `scripts/lint/forbidden-terms.test.ts`, `infra/bootstrap/ci-role.test.ts` — `scripts/lint/no-ses-receiving.test.ts`, `scripts/lint/chokepoint.test.ts`, `scripts/lint/forbidden-terms.test.ts` e `infra/bootstrap/ci-role.test.ts` cubren cada fixture.
- **Notas de la matriz** · Excepción §2.1

## Evidencia que se guarda

- Salida de vitest de `[FL-110]` y el job de CI con los guards en verde sobre el commit de la corrida.
