# FL-074 · WhatsApp proactivo sin reclamo abierto

| Campo | Valor |
|---|---|
| Área | I · Política de canal |
| Actores | operador, sistema |
| Canal | WhatsApp |
| Disparador | plantilla `reclamo_novedad` a un cliente sin reclamo abierto |
| Reglas | `CH-WA-CUSTOMER-INITIATED` |
| Depende del modelo | No |
| Fuente | `docs/flows-catalog.md` FL-074; `docs/test-plan.md` §2.2, §4.3 y §4.5 |

## Entrada

- Mundo `qa-<runId>-sc13`; persona clon `C09'` sin reclamo abierto.
- Principal `OPERATOR` con la plantilla `reclamo_novedad`.

## Pasos

1. `console.customers.compose(COMPLAINT_UPDATE, WHATSAPP)` con la plantilla, para el cliente sin reclamo.
2. `conv.settleProbe`; `snapshot`.

## Resultado esperado

- **R1** · Cinta `BLOCKED` con `ruleIds ∋ CH-WA-CUSTOMER-INITIATED`. _Dónde:_ `snapshot.tape`.

Negativos (se asiertan después de la quiescencia, `CONVENCIONES.md`):

- **N1** · Ningún mensaje de WhatsApp sale para el cliente.

## Oráculo

No depende del modelo: `CH-WA-CUSTOMER-INITIATED` bloquea todo WhatsApp proactivo que no sea la novedad de un reclamo abierto del cliente.
